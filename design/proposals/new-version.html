When there's a newer Crake. Two cases. (1) A package manager updated Crake: its service (craked) was restarted on the new version, but the app keeps running the old one until it's restarted, as desktop apps do. Crake knows, by comparing its version with craked's (nothing leaves the computer), and says so. (2) On a Mac or Windows install that no package manager updates (a .pkg opened by hand, the .exe), nothing tells the user a new version is out; Crake would have to ask dorhawk.software.
1. Updated: restart to finish (every system)
A notice at the top of the panel, while craked is newer than the app. "Restart" starts the new Crake in the old one's place. No setting, nothing sent anywhere.

General

Tell me when there's a new version
Once a day Crake asks dorhawk.software which version is the newest. It sends nothing about you, this computer or your tunnels; the site sees an address asking, as with any web page.
Decision for (2): Crake's rule is "nothing is sent anywhere". Asking for the newest version is a request to dorhawk.software, so: off until the user switches it on (shown here; the notice in (1) still works without it), or on by default on Mac and Windows installs that nothing else updates, with this setting to switch it off. Linux, Homebrew and winget users never need it: their package manager does it.
